# Índice de skills (cuándo usar cada una)

## A. Del web al APK
| Skill | Cuándo usarla | Origen |
|---|---|---|
| **web-a-apk** | Convertir una web o PWA en app de Android: elegir camino, construir con GitHub Actions, firmar. | Original |
| github-actions | Flujos de GitHub Actions para compilar apps móviles (React Native) en la nube. | Callstack (MIT) |

## B. Probar y verificar
| Skill | Cuándo usarla | Origen |
|---|---|---|
| **verificar-apk** | Hay un APK o AAB listo: instalarlo, intentar romperlo y dar un informe. | Original |
| android-testing | Pruebas de una app de Android nativa (JUnit, MockK y similares). | lennonpetrick (MIT) |
| security-audit | Auditoría de seguridad de Android basada en OWASP MASVS. | liuyi0808 (MIT) |
| play-store | Lista de requisitos y políticas de Google Play. Está enfocada en apps financieras; sirve de base general. | liuyi0808 (MIT) |

## Notas
- No incluí `privacy-audit` (de liuyi0808): está hecha para apps de préstamos y no aplica a tus apps.
- Para Flutter hay [zakariaf/Flutter-Skills](https://github.com/zakariaf/Flutter-Skills) (MIT). No la copié porque no sé si usarás Flutter.
- `kotlin-footguns` (maxrave-dev) es útil pero tiene licencia GPL-3.0. No la copié para no mezclar licencias.
- Las skills de la interfaz web, pruebas web y fluidez están en `app-skills-jeiler`.
